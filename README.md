## Utility classes

The project includes Tailwind-style utility classes located in `src/styles/utilities.scss`. However, Tailwind is not installed as a dependency — these utility classes are custom-made and implemented specifically for this project. They are not generated by any tool, so if you want to add new utility class, simply add it to the file.

## SVG sprites

The project uses SVG sprites for icons. They are stored in `src/assets/icons` and generated using `vite-plugin-svg-spritemap`. To add a new icon, simply place it in the appropriate folder and restart the development server (press `R` and then `Enter` in the console).

If you need a monochrome icon (so you can control its appearance using `fill` or `stroke`), place it in the `src/assets/icons/monochrome` directory.

If the icon contains fixed colors and should preserve them, place it directly in the `src/assets/icons` directory.

The plugin automatically generates the spritemap and makes it available at the /\_\_spritemap URL.

You can then use it in your code like this:

```html
<svg>
  <use href="/__spritemap#icon-name"></use>
</svg>
```

Or, if you want to use it as an image:

```html
<img src="/__spritemap#icon-name-view" alt="Icon description" />
```

```css
.element {
  background-image: url('/__spritemap#icon-name-view');
}
```

## ScrollAnimator module

If your animated elements use `transform`, wrap them in an additional container and apply the animation classes to that wrapper instead. `transform` creates a new stacking context and can interfere with scroll-triggered animations.

If you need a staggered delay in your animation, use a wrapper element as the trigger and add the `data-animate-on-scroll` attribute to it. Place `data-animate-item` on the child elements that should animate. These children can then be styled via state inheritance, for example:

```css
.wrapper.hidden .child {
  translate: 0 20px;
  opacity: 0;
}

.wrapper.visible .child {
  scale: 1.05;
}
```

### Timing control in staggered animations

- Use the `--delay` CSS variable to define the stagger step between items.
- Define only the `transition-property` on animated elements (duration and delay are handled via variables).
- To override the default duration, set the `--transition-duration` variable on the element with the `data-animate-on-scroll` attribute or set `transition-duration` directly on the animated items.
